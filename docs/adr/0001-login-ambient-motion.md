# 登录页环境动效是全站"装饰动效 = slop"立场的唯一例外

DESIGN.md 的全站立场是装饰动效即 slop（背景光斑静态不动画），但登录页是品牌的第一眼，2026-09 经评审决定为其加一层慢节奏电影感的环境动效（星云漂移 / 星闪 / 流星循环 / 地平线辉光脉动 + 卡片一次性入场 + 按钮 hover sheen），气质与"安静高级"的系统调性保持一致，而非游戏感炫技。

实现约束（防止例外膨胀，后续改动不得越过）：

- 纯 CSS/SVG，零新依赖、零 JS 动画库；只动 transform/opacity
- 叠加层方案：静态场景仍为 `login-bg.svg` 资产，动效元素内联在登录组件的 SVG 层——background-image 里的 SVG 无法被 CSS 驱动，这是叠加层存在的根因
- 节奏克制：流星 7s / 9.5s 两颗错峰、星云漂移 75s / 90s、缓动一律 `var(--ease-fluid)`
- `prefers-reduced-motion: reduce` 下全部静止（全局规则同时断开无限循环，避免 0.01ms 时长空转）
- 唯一强调色仍为 `#0071e3`；动效装饰只用已有浅蓝系（#4da3ff / #66b3f0 / #cfe4ff），不新增强调色

Rejected alternatives:

- 赛博活泼档（高频流星 / 扫描线流动 / 常驻呼吸辉光）——与后台克制气质割裂，易滑向 DESIGN.md 定义的 slop
- JS 动画库（GSAP / anime.js 等）——违反项目"不引入计划外依赖"反模式
- 把静态 login-bg.svg 整体内联进组件再动画——可行但组件膨胀近 130 行，叠加层以最小增量达成同等效果
